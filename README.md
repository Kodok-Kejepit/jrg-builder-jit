# jrg-builder-jit

Repo ini **khusus untuk membangun dan menguji JRGJIT**, mesin keempat JRG (JawaRustGo++) yang menurunkan bytecode
ke kode mesin lewat Cranelift (`jrgc --jit`), lewat GitHub Actions — kompilasi, suite tes lengkap, sapuan contoh,
dan sapuan sanitizer runtime LLVM. Isinya salinan kode yang sedang diuji, didorong apa adanya; bukan tempat
pengembangan, jadi issue dan pull request tidak diproses di sini. Build umum lainnya ada di `jrg-builder`.

- Kode sumber dan rilis resmi: https://github.com/Kodok-Kejepit/jrg
- Dokumentasi: https://jrg-lang.org
