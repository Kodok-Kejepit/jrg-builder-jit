JawaRustGo++ (JRG) adalah bahasa pemrograman dengan pesan galat berbahasa Indonesia. Ditulis dengan Rust, bentuk kodenya mirip Rust dan Go. Satu program bisa dijalankan lewat interpreter, mesin virtual, atau dikompilasi jadi program native, dan hasilnya sama.

Pasang JRG Tur singkat Belajar dari nol
```jrg rapor.jrg struct Murid { pub nama: string, pub nilai: int } pub fn main() { let kelas = [ Murid { nama: "Ani", nilai: 92 }, Murid { nama: "Budi", nilai: 78 }, Murid { nama: "Citra", nilai: 85 }, ] for _, m in kelas.filter(|m| m.nilai >= 80) { wok("""${m.nama} lulus dengan ${m.nilai}""") } let rata = arr::sum(kelas.map(|m| m.nilai)) / len(kelas) wok("rata-rata kelas:", rata) } ``` ```keluaran Ani lulus dengan 92 Citra lulus dengan 85 rata-rata kelas: 85 ```

Galat yang bisa dibaca

Pesannya menyebut letak masalah, apa yang salah, dan jalan keluarnya.

```sh $ jrgc harga.jrg kepentok di baris 2 waktu jalan. keterangannya di bawah. error: index [3] di luar batas — array ini isinya 3 elemen (index valid: 0..2, atau -1..-3 kalau mau hitung dari belakang) --> harga.jrg:2:5 | 2 | wok(harga[3]) | ^^^^^^^^ ```

Isi kotaknya

Yang kamu dapat sesudah memasang JRG.

Tiga mesin

Interpreter untuk coba-coba, VM bytecode (--vm) yang lebih cepat, dan kompilasi native lewat LLVM (--emit-llvm).

{BUILTIN} fungsi bawaan

Teks, koleksi, berkas, waktu, JSON, regex, HTTP, SQLite, kanvas, suara, dan numerik. Cari dengan jrgc --cari.

Pustaka std/

14 modul (set, antrean, heap, CSV, uang, tabel…) plus mesin game 2D, semuanya ditulis dalam JRG.

Bahasa lain

Panggil C, C++, Rust, Go, Python, JavaScript, PHP, Lua, Java, Kotlin, .NET, dan WebAssembly.

Proyek dan paket

jrgm membuat proyek, mengurus dependensi lewat git, menjalankan tes, merapikan, dan memeriksa kode.

Sampai ke HP

Bungkus program jadi APK Android dengan jrgm apk. Ada juga JRG IDE yang jalan di HP.
